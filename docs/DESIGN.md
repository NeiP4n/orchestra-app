# Дизайн интерфейса Orchestra

Цель: компактно, читаемо, без лишнего. Всё, что можно убрать с экрана, убрано; всё, что нужно в данный момент, видно без переходов.

## Правила
1. **Три цвета и всё.** Чернила (нейтральный серый, весь обычный текст), голубой (структура: рамки, активные элементы, ссылки), янтарный (внимание: предупреждения, ошибки, то, что ждёт вас). Красного, зелёного, синего, фиолетового нет. Состояние различается ещё и значком: `✓` готово, `✗` ошибка, `…` в работе, `?` ждёт вас.
2. **Без градиентов и заливок.** Все панели на одном фоне страницы. Границы цветом структуры (голубой), в диффах добавленное и удалённое различаются цветом текста, а не плашками.
3. **Дизеринг как текстура, не как украшение.** Символы `░▒▓` только для разделителей и «пустых» областей; текст на них не пишем. Фаза узора (`phase`) выделена параметром: позже анимация одним общим тиком 8–12 кадров/с. Отключается `ORCHESTRA_NO_MOTION=1`, останавливается в простое и когда окно не в фокусе.
4. **Плотность.** Одна строка статуса вместо шапки, вкладки сессий в одну строку, сообщения без пустых промежутков между репликами одного автора. Диалоги небольшие и с рамкой, не на весь экран.
5. **Одна клавиша на частое действие.** Быстрые ответы и действия «Общества» остаются кнопками в строке; палитра команд по Ctrl+K.

## Схема экрана (120x40)
```
┌ orchestra ░▒▓ проект · сессия · модель/источник ─────────── ?2 ✓5 ┐
│ вкладки:  [1 api] 2 тесты  3 общество*  +                        │
├──────────────────────────────────────────────────────────────────┤
│ реплики (текст серым, вызовы инструментов голубым, ошибки        │
│ янтарным, без заливок)                                           │
│                                                                  │
├ ░▒▓░▒▓░▒▓░▒▓░▒▓░▒▓░▒▓░▒▓░▒▓░▒▓░▒▓░▒▓░▒▓░▒▓░▒▓░▒▓░▒▓░▒▓░▒▓░▒▓░▒▓ ┤
│ > ввод                                          [ответ1] [ответ2] │
└──────────────────────────────────────────────────────────────────┘
```
