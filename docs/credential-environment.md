# Настройка credentials после удаления из кода

Секреты не имеют встроенных значений или запасных значений.
Не сохраняйте реальные значения в репозитории, примерах, чатах и логах.

- `ORCHESTRA_PASSWORD`: пароль уже запущенного сервера Orchestra для `script/autonomous-council-daemon.ts`. Это та же переменная, которую использует CLI. Без неё daemon завершится с русским сообщением до запуска работы.
- `ORCHESTRA_ANTIGRAVITY_CLIENT_SECRET`: OAuth client secret, соответствующий настроенному Antigravity client ID. Должен быть доступен процессу Orchestra и процессу `scripts/check-quota.mjs`. Нужен для обмена кода и обновления OAuth-токенов. Импорт или обнаружение провайдера не требует секрета.

Задайте переменные через защищённое окружение процесса/службы. Существующий токен не заменяет client secret при следующем обновлении. Не подставляйте новый client secret от другого OAuth client ID: эта правка не меняет client ID и не перевыпускает credentials.

Удаление из текущего дерева не отзывает ранее опубликованные credentials и не очищает историю. Перевыпуск выполняет владелец соответствующего OAuth-приложения; пароль daemon нужно заменить, если старый использовался.

Проверки:

```sh
python3 script/check-removed-credentials.py
bun test ./script/credential-env.test.ts
```

Проверка fingerprints читает только tracked-файлы текущего дерева, не выводит найденные значения и не проверяет историю. Её также запускает CI secret-scan job.
