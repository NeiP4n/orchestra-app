<h1 align="center">Orchestra</h1>

<p align="center">Терминальный ИИ-агент и оркестратор разработки для команд: мультиплеер по локальной сети, ИИ-команды со специализациями и ролями, DoD-доска проекта, заметки и банк идей.<br>Windows, Linux, macOS и Android.</p>

<p align="center"><a href="README.md">English</a> | <a href="README.ru.md">Русский</a></p>

## Установка

Одна команда; git и Bun установщик поставит сам, если их нет.

| Система | Команда |
| --- | --- |
| Windows (PowerShell) | `irm https://raw.githubusercontent.com/NeiP4n/orchestra-app/main/installer/get.ps1 \| iex` |
| Linux / macOS | `curl -fsSL https://raw.githubusercontent.com/NeiP4n/orchestra-app/main/installer/get.sh \| sh` |

Потом открой новый терминал и запусти `orchestra-app` (или `orchestra`).

**Обновление:** повторный запуск команды установки.

## Что внутри

- **Комнаты в локальной сети** — хост открывает сессию, остальные подключаются по коду: участники, роли, разрешения и общая DoD-доска. Кроссплатформенная работа между Windows, Linux и macOS.
- **ИИ-команды** — оркестратор раздаёт задачи ролям (архитектор, разработчик, тестировщик, ревьюер…). Есть готовые шаблоны, свои настраиваются в `/teams`.
- **Федеративные группы** — отдельный групповой оркестратор наблюдает за проектными оркестраторами и их работниками, сводит прогресс и тикеты, получает события о жизненном цикле задач. Открой «Группы» и запусти координатор.
- **DoD-доска проекта** — `.orchestra/dod.yaml` (или `.opencode/dod.yaml`) в виде интерактивной панели прогресса: что готово, в работе и заблокировано, с командами верификации.
- **Банк идей** — приватные идеи из твоих сессий и общий глобальный каталог с быстрым поиском (отправка только с согласия).
- **Заметки** — проектные заметки в Markdown с интеграцией в контекст моделей.
- **Hub и реестр инструментов** — единый каталог CLI- и MCP-инструментов: установка и подключение для моделей, Nushell в качестве современной рабочей оболочки ИИ.
- **Мини-скиллы** — настраиваемые кнопки над полем ввода: Analyze, Plan, Debug, Review, Test…
- **Общие лимиты** — агенты одного провайдера или модели координируют задержки вместе, предотвращая блокировку квоты.
- **Режим для телефона** — `/mobile` сворачивает боковые панели в направляющие по краям; в Termux и Android-оболочках включается автоматически.
- **Русский и английский** интерфейс (`/language`).

## Архитектура монорепозитория

Платформа Orchestra разработана на Effect v4 и разделена на строгие слои:

- `packages/schema` — схемы контрактов данных и хранилища (Effect Schema).
- `packages/protocol` — канонический контракт HTTP и WebSocket API (Effect HttpApi).
- `packages/core` — доменное ядро: сессии, runner, координатор очередей, инструменты и шина событий.
- `packages/server` — транспортный HTTP-сервер и потоки SSE-событий.
- `packages/client` — генерируемые клиенты (Promise, Effect и Solid).
- `packages/cli` — CLI-интерфейс, фоновый демон-сервис и ACP.
- `packages/tui` — терминальный UI на SolidJS и OpenTUI.
- `packages/app` — веб- и десктоп-оболочка.

## Разработка

```bash
bun install
bun run dev
```

`bun run check` — линтер и проверка типов для всего монорепозитория. Подробнее в [CONTRIBUTING.md](CONTRIBUTING.md) и [AGENTS.md](AGENTS.md).
