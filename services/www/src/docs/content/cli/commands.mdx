---
title: "Commands"
description: "Reference for the orchestra command line."
---

Every command accepts `--help` for its full flag list, for example `orchestra run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ orchestra run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: Orchestra review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @orchestra/cli
      - run: orchestra run --standalone --model anthropic/claude-sonnet-4-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ orchestra run --model anthropic/claude-sonnet-4-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ orchestra run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ orchestra run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ orchestra run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ orchestra run --agent build "Fix the failing test"
```

View all subcommands and flags.

```bash
$ orchestra run --help
```

## mini

Starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ orchestra mini
```

Continue the last session.

```bash
$ orchestra mini --continue
```

Start with a model and an initial prompt.

```bash
$ orchestra mini --model anthropic/claude-sonnet-4-5 --prompt "Summarize this repository"
```

View all subcommands and flags.

```bash
$ orchestra mini --help
```

## session

Manages sessions.

```bash
$ orchestra session list
```

Limit the list and print JSON.

```bash
$ orchestra session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ orchestra session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ orchestra session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ orchestra session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ orchestra session import session.json
```

Import into a specific directory.

```bash
$ orchestra session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ orchestra session --help
```

## auth

Manages AI providers and credentials.

```bash
$ orchestra auth list
```

List them as JSON.

```bash
$ orchestra auth list --format json
```

Log in to a provider.

```bash
$ orchestra auth login anthropic
```

Log in with a specific authentication method.

```bash
$ orchestra auth login anthropic --method key
```

Log out of a saved account.

```bash
$ orchestra auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ orchestra auth switch anthropic work
```

View all subcommands and flags.

```bash
$ orchestra auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ orchestra mcp list
```

Add a remote server.

```bash
$ orchestra mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ orchestra mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ orchestra mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ orchestra mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ orchestra mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ orchestra mcp logout sentry
```

View all subcommands and flags.

```bash
$ orchestra mcp --help
```

## plugin

Manages plugins.

```bash
$ orchestra plugin list
```

Include built-in server plugins.

```bash
$ orchestra plugin list --builtin
```

Install a plugin and add it to the global configuration.

```bash
$ orchestra plugin add @example/orchestra-tui
```

Check package plugins for updates.

```bash
$ orchestra plugin check
```

Update package plugins.

```bash
$ orchestra plugin update
```

Remove a plugin from global configuration.

```bash
$ orchestra plugin remove @example/orchestra-tui
```

View all subcommands and flags.

```bash
$ orchestra plugin --help
```

## stats

Shows shareable usage statistics.

```bash
$ orchestra stats
```

Show the last 7 days.

```bash
$ orchestra stats --days 7
```

Show model usage.

```bash
$ orchestra stats --models
```

Show cost and token details.

```bash
$ orchestra stats --cost
```

Print JSON instead of a report.

```bash
$ orchestra stats --json
```

View all subcommands and flags.

```bash
$ orchestra stats --help
```

## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ orchestra serve
```

Bind to all interfaces on a fixed port.

```bash
$ orchestra serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ orchestra serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ orchestra serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ orchestra pair
```

Use an external URL in the links.

```bash
$ orchestra pair --url https://dev.example.com
```

View all subcommands and flags.

```bash
$ orchestra pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ orchestra service start
```

Restart it.

```bash
$ orchestra service restart
```

Show its status.

```bash
$ orchestra service status
```

Stop it.

```bash
$ orchestra service stop
```

Read a setting.

```bash
$ orchestra service get hostname
```

Set a setting.

```bash
$ orchestra service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ orchestra service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ orchestra service set env ORCHESTRA_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ orchestra service unset hostname
```

View all subcommands and flags.

```bash
$ orchestra service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ orchestra reload
```

## api

Makes a request to the running server.

```bash
$ orchestra api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ orchestra api session.list --param limit=10
```

Send a JSON body.

```bash
$ orchestra api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ orchestra api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ orchestra api --help
```

## upgrade

Upgrades Orchestra to the latest or a specific version. Alias: `update`.

```bash
$ orchestra upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ orchestra upgrade 2.0.21 --method bun
```

View all subcommands and flags.

```bash
$ orchestra upgrade --help
```

## uninstall

Removes Orchestra and all related files.

```bash
$ orchestra uninstall
```

Preview what would be removed.

```bash
$ orchestra uninstall --dry-run
```

View all subcommands and flags.

```bash
$ orchestra uninstall --help
```
