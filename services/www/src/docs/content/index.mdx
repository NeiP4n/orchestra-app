Orchestra is an open source AI coding agent. It’s available as a terminal-based interface, desktop app, or web app.

The npm package uses a postinstall script to select the native `orchestra` binary for your platform. The Bun and pnpm commands
explicitly allow the required script; Vite+ requires no additional flag.

Windows package managers are not supported.


Download a standalone CLI binary for your platform.

- **macOS:** [Apple silicon](https://github.com/NeiP4n/orchestra-app) · [Intel](https://github.com/NeiP4n/orchestra-app) · [Intel (baseline)](https://github.com/NeiP4n/orchestra-app)
- **Windows:** [ARM64](https://github.com/NeiP4n/orchestra-app) · [x64](https://github.com/NeiP4n/orchestra-app) · [x64 (baseline)](https://github.com/NeiP4n/orchestra-app)
- **Linux (glibc):** [ARM64](https://github.com/NeiP4n/orchestra-app) · [x64](https://github.com/NeiP4n/orchestra-app) · [x64 (baseline)](https://github.com/NeiP4n/orchestra-app)
- **Linux (musl):** [ARM64](https://github.com/NeiP4n/orchestra-app) · [x64](https://github.com/NeiP4n/orchestra-app) · [x64 (baseline)](https://github.com/NeiP4n/orchestra-app)

## Web

Access the Orchestra web interface with the `orchestra pair` command.

```bash
$ orchestra pair

  URLs      http://127.0.0.1:49374
  Username  orchestra
  Password  ********
```

## Docker

Docker images use versioned tags, for example `ghcr.io/NeiP4n/orchestra-app:2.0.0`.

## Connect

Orchestra has built in support for many LLM providers - you can connect to them
directly [in the TUI](/cli/providers) with `/auth`.

See [Providers](/providers) to configure custom providers.

If you'd like easy access to all the best coding models you can try out
[Orchestra Console](/console).

You can also try [`opencode-go`](/console/go) a $10/month subscription
plan that grants you access to the best open source models.

## Customize

Make Orchestra your own by editing the [Orchestra config](/config), [loading plugins](/plugins), [connecting MCP
servers](/mcp-servers), or [creating commands](/commands). For terminal interface themes and keybindings, see [CLI
settings](/cli/config).
